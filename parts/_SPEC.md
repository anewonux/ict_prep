# 华为 ICT 大赛网络赛道备考资料 —— 统一写作规范（所有分册必须遵守）

## 0. 面向读者
- 读者是**已有数通网络基础**的参赛选手（懂 TCP/IP、会基本 VRP 命令、了解 VLAN/静态路由/OSPF 基本概念）。
- 目标：把"懂一点"变成"能考高分 + 能上机做实验"。因此**理论要讲透原理（为什么），不能只抄命令**。

## 1. 标题层级（强制格式）
每章用一级标题，格式严格为：

```
# <方向>-<HCIA|HCIE>-章节<编号>-<章节名>
```

方向只能是这 4 个：`数通`、`DCN`、`安全`、`WLAN`。
示例：
- `# 数通-HCIA-章节3-以太网与VLAN技术`
- `# DCN-HCIE-章节2-VXLAN与BGP-EVPN深入`
- `# 安全-HCIA-章节2-防火墙基础与安全策略`
- `# WLAN-HCIE-章节4-高密度部署与射频优化`

一级标题下用二级 `##` 表示知识点，三级 `###` 表示知识点的子块。

## 2. 每个知识点（`##` 级）必须包含以下子块（顺序固定）
1. `### 考点定位` —— 一句话说明该考点在比赛中怎么考、分值比重、易错点。
2. `### 原理精讲` —— 讲清机制、报文交互、状态机、表项字段。**必须解释"为什么这么设计"**。涉及报文的地方给出字段表（Markdown 表格）。
3. `### 关键概念对照表` —— 用 Markdown 表格做对比/参数速查（如协议对比、报文类型、定时器默认值、状态迁移）。
4. `### 华为设备配置` —— 真实 VRP 命令，放 ```bash 或 ```text 代码块，**每一行命令后加 `//` 或 `#` 注释说明作用**。命令必须语法正确、贴合真实产品（见第 5 节型号表）。
5. `### 示意图` —— 至少一个 ```mermaid 代码块（语法见第 4 节），必要时再加一个 ASCII 拓扑图。
6. `### 真题精练` —— 见第 3 节。每章至少 **6 道**，覆盖单选/多选/判断/填空/简答/排错实操。
7. `### 易错点与排错` —— 列出 3~6 条考试陷阱和 display/ debugging 排错命令。

> 若某个子块对某知识点不适用（例如概念章节没有配置），可省略，但**不得连续两个知识点都省略原理或真题**。

## 3. 真题精练规范
每条题目格式：

```
**Q1.【真题·单选】** 题干……
A. ……  B. ……  C. ……  D. ……

> **答案：B**
> **解析**：……（讲清干扰项为什么错，必要时引用 RFC / 华为产品文档结论）
```

题型标签统一用：`【真题·单选】`、`【真题·多选】`、`【真题·判断】`、`【真题·填空】`、`【真题·简答】`、`【真题·排错】`、`【真题·实验】`。

**真实性要求（重要）**：
- 题目要**贴近华为 ICT 大赛与华为 HCIA/HCIP/HCIE 认证真题的命题风格与高频考点**：考原理、考默认值、考报文细节、考排错判断。
- 在**每个分册文件最开头**加一行提示块：
  `> 本册真题依据华为 ICT 大赛历年公开赛题方向、华为认证考试真题回忆与官方教材例题整理改写，用于自测训练；正式参赛请以大赛官方考试大纲与题库为准。`
- 严禁编造"2023 年国赛第 X 题原题"这类精确出处；标注就用 `【真题·单选】` 这种题型标签即可。
- 每道题必须**给出正确答案和完整解析**，不能只给题。

## 4. 示意图规范（Mermaid）
统一使用 ```mermaid 围栏。四种图型按场景选用：

- **拓扑图**用 `flowchart LR` 或 `graph TB`，设备用 `[]`/`()`，链路标注带宽用 `-->|10GE|`。
- **报文交互/时序**用 `sequenceDiagram`。
- **状态机/流程**用 `stateDiagram-v2` 或 `flowchart TD`。
- **对比/占比**用 `pie` 或 `mindmap`。

语法硬性要求（否则渲染失败）：
- 节点 ID 只用英文/数字（如 `SW1`, `CoreA`），中文一律放进标签 `SW1["接入交换机 S5731"]`。
- 标签里含 `()`、`,`、`:`、`/` 时**必须**用双引号包住标签。
- 不要使用 `style ... fill:` 之外的冷门语法；避免 `subgraph` 里嵌套过深。
- 链路标签避免用 `|` 以外的符号。
- 每个 mermaid 块不超过 25 行，复杂拓扑拆成多张图。

## 5. 必须使用的真实产品与版本（不要写虚构型号）
| 方向 | 产品系列 |
|---|---|
| 数通/园区 | CloudEngine S5731/S6730/S12700（园区）、NE40E/NE8000（路由器）、AR6000 系列（AR6120/AR651） |
| DCN | CloudEngine 6865/6863/16800/8850、CE12800；iMaster NCE-Fabric |
| 安全 | HiSecEngine USG6000E（USG6510E/USG6520E）、USG12000、HiSec Insight、NIP（IPS）、AntiDDoS |
| WLAN | AirEngine 5761/6761/8760、AC6805/AC6605、AirEngine 9700S、iMaster NCE-Campus、WLAN Planner |
| 通用 | VRP V200/V300/V600、eNSP、iMaster NCE |

配置命令风格：华为 VRP。
- 系统视图 `system-view`，接口 `interface GigabitEthernet0/0/1`，VLAN `vlan batch 10 20`。
- 保存 `save`，查看 `display current-configuration`。
- 防火墙用 `firewall zone trust` / `security-policy` / `nat-policy`。
- 无线控制器用 `wlan` 视图 / `capwap source interface` / `vap-profile`。

## 6. 写作风格
- 中文，专业但可读；多用表格、编号步骤、对比。
- **不要写废话开头**（不要"在当今信息化时代……"），直接从标题进入内容。
- 每个知识点正文 ≥ 400 字的中文实质内容（不含表格与代码）。
- 术语首次出现给出英文缩写全称，例如 OSPF（Open Shortest Path First，开放式最短路径优先）。
- 数值必须准确：如 OSPF Hello 默认 10s/Dead 40s（广播型）、STP Forward Delay 15s、BPDU 2s、VXLAN VNI 24 bit、VLAN ID 12 bit、Ethernet MTU 1500、IPSec ESP 协议号 50、AH 51、IKE 500/4500。

## 7. 文件输出
- 每个分册**只写自己的那一个文件**，路径由任务指定，写完即结束。
- 文件顶部先写分册说明（含第 3 节的真题提示块），再写各章。
- 不要在文件里写"本文由 AI 生成"之类的元信息。
- 不要修改 `parts/_SPEC.md` 和别人的分册文件。
