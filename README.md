## 每个知识点的结构

所有知识点统一按 7 个板块组织，便于"建立框架 → 啃透原理 → 刷题验证"：

1. **考点定位** —— 这个考点在比赛里怎么考、分值、易错点
2. **原理精讲** —— 机制、报文交互、状态机、表项字段，重点解释"为什么这么设计"
3. **关键概念对照表** —— 协议对比、默认值、参数速查
4. **华为设备配置** —— 真实 VRP 命令，逐行注释
5. **示意图** —— Mermaid 拓扑/时序/状态机（已渲染成 PNG）
6. **真题精练** —— 带答案与解析，含干扰项错因
7. **易错点与排错** —— 考试陷阱 + `display`/`debugging` 排错命令

### 关于真题

题目依据华为 ICT 大赛历年公开赛题方向、华为认证考试真题回忆与官方教材例题**整理改写**，用于自测训练，每题均附答案与解析。**未标注任何具体的"某年某题"出处**；正式参赛请以大赛官方考试大纲与题库为准。

### 关于设备与版本

配置命令均为真实华为 VRP 语法，覆盖 CloudEngine S5731/S6730/S12700/6865/16800、NE40E/NE8000、AR6120/AR651、HiSecEngine USG6000E/USG12000、AC6805、AirEngine 系列等。少数随版本变化的命令已明确标注"以所用版本文档为准"，未把不确定语法写成确定事实。
